# Forex Signal System — เวอร์ชันรันบนคลาวด์ (ไม่ต้องเปิดเครื่องตัวเองทิ้งไว้)

ระบบวิเคราะห์สัญญาณเทรด Forex แบบ rule-based จากอินดิเคเตอร์ทางเทคนิค (EMA crossover,
RSI, MACD, Stochastic, ADX, Bollinger Bands) ติดตาม **14 คู่เงิน**

- **`forex_signals.py`** — ดึงราคา, คำนวณอินดิเคเตอร์, สรุปสัญญาณ BUY/SELL/HOLD,
  เขียนผลลง `signals.json` (รวมแท่งเทียนย้อนหลังสำหรับวาดกราฟ), ส่งแจ้งเตือน Telegram เมื่อสัญญาณเปลี่ยน
- **`.github/workflows/forex-signals.yml`** — ตัวจับเวลาที่รันสคริปต์ข้างบนให้อัตโนมัติ
  **บนเซิร์ฟเวอร์ของ GitHub** ทุก 30 นาที ตลอด 24 ชม. โดยไม่ต้องเปิดคอมของคุณเลย
- **`dashboard.html`** — เว็บแดชบอร์ด: กราฟแท่งเทียนจริง (เขียว/แดง) ต่อคู่เงิน, การ์ดสัญญาณ,
  ราคาวิ่งขึ้น/ลงแล้วกระพริบสี, **ติดตั้งลงหน้าจอมือถือได้เหมือนแอป (PWA)**,
  และมี **"โหมดสด" (Live mode)** ที่ดึงราคาตรงจากเบราว์เซอร์คุณเองทุก ~2 นาทีตอนเปิดแอปอยู่
- **`manifest.json`, `service-worker.js`, `icon-*.png`** — ไฟล์รองรับการติดตั้งเป็นแอปบนมือถือ
- **`indicators.py`** — ฟังก์ชันอินดิเคเตอร์/feature ที่ใช้ร่วมกันทั้งฝั่งสัญญาณและฝั่ง ML
- **`ml/train_model.py`** + **`.github/workflows/train-model.yml`** — เทรนโมเดล machine learning
  จริงจากข้อมูลราคาย้อนหลัง ให้ค่า "ความน่าจะเป็น" แยกต่างหากจากสัญญาณกฎตายตัว (รายละเอียดด้านล่าง)

ทั้งหมดนี้ใช้ **GitHub ฟรี** (public repo ใช้ Actions ได้ไม่จำกัดโควตา) ไม่มีค่าใช้จ่าย

## เกี่ยวกับ 4 เรื่องที่ถามเพิ่ม

| ที่ขอ | ทำได้จริงแค่ไหน |
|---|---|
| ติดตั้งลงมือถือ | ✅ ทำเป็น PWA แล้ว — เปิดเว็บแล้วกด "เพิ่มลงหน้าจอโฮม" ได้ทั้ง iOS/Android (ขั้นตอนด้านล่าง) |
| กราฟขึ้นลงจริง เขียว/แดง | ✅ ใส่กราฟแท่งเทียนจริงต่อคู่เงินแล้ว (แตะการ์ดเพื่อดูกราฟใหญ่) พร้อมราคาที่กระพริบเขียว/แดงเมื่อเปลี่ยน |
| แสดงสัญญาณเรียลไทม์ | ⚠️ บางส่วน — โหมดปกติอัปเดตทุก 30 นาที (ข้อจำกัดของ cron ฟรี), เพิ่ม "โหมดสด" ที่ดึงตรงทุก ~2 นาทีตอนเปิดแอปให้ แต่ไม่ใช่ tick-by-tick แบบโบรกเกอร์จริง |
| เพิ่มความแม่นยำ | ⚠️ เพิ่ม ADX + Stochastic กรอง false signal แล้ว และเพิ่มโมเดล ML จริงที่เรียนรู้จากข้อมูลย้อนหลัง (ด้านล่าง) — แต่ยังไม่มีระบบไหนรับประกันความแม่นยำในการทำนายราคาได้ เป็นข้อจำกัดพื้นฐานของตลาด ไม่ใช่เรื่องแก้ด้วยโค้ดล้วนๆ |
| เพิ่มจำนวนคู่เงิน | ✅ จาก 5 → 14 คู่ (major + cross ที่นิยม) ปรับเพิ่ม/ลดได้เอง แต่ติดเพดานโควตา API ฟรี ดูตารางด้านล่าง |

## 🤖 เกี่ยวกับโมเดล ML (เพิ่มใหม่)

`ml/train_model.py` เทรน **โมเดล machine learning จริง** (ไม่ใช่กฎตายตัว) จากข้อมูลราคาย้อนหลัง
ที่ดึงสะสมไว้ทุกครั้งที่รัน — โมเดลจะทำนาย **"ความน่าจะเป็นที่ราคาจะขึ้น อีก 4 แท่งข้างหน้า (~1 ชม.)"**
แล้วแสดงเป็นเปอร์เซ็นต์แยกต่างหากในการ์ด (มีไอคอน 🤖) ควบคู่ไปกับสัญญาณกฎตายตัวเดิม ไม่ได้แทนที่กัน

**สิ่งที่ต้องเข้าใจให้ตรงก่อนใช้:**

- ตัวเลข "แม่นยำย้อนหลัง" ที่แสดง คือผลทดสอบกับข้อมูลส่วนที่โมเดล**ไม่เคยเห็นตอนเทรน**
  (ทดสอบแบบ time-based split ไม่ใช่สุ่ม เพื่อไม่ให้แอบ "จำ" อนาคตมาก่อน) แต่ก็ยังไม่ได้หักค่า
  spread/ค่าคอมมิชชั่น/จังหวะการเข้าออเดอร์จริง ดังนั้น "แม่นยำ 55%" ไม่เท่ากับ "ชนะ 55% ของการเทรดจริง"
- ราคา FX ระยะสั้นใกล้เคียงการโยนเหรียญมาก โมเดลที่ทำได้ 53-56% ในระยะยาวถือว่ามีนัยสำคัญแล้วในวงการนี้
  ไม่ใช่เรื่องน่าผิดหวังถ้าตัวเลขไม่ได้สูงลิ่ว — และถ้าต่ำกว่า baseline (แพ้การทายข้างที่เกิดบ่อยกว่า)
  ระบบจะบอกตรงๆ ในผลลัพธ์ ไม่ปิดบัง
- ข้อมูลย้อนหลังของ API ฟรีมีจำกัด สคริปต์นี้จึง **สะสมข้อมูลไว้ใน `ml/data/*.csv` ทุกครั้งที่รัน**
  ยิ่งรันบ่อย/นานเท่าไหร่ ยิ่งมีข้อมูลเทรนมากขึ้น ควรรันซ้ำเป็นระยะ (workflow ตั้งไว้ทุกวันจันทร์อัตโนมัติ
  หรือกด Run workflow เองเพิ่มได้)
- **โหมดสด (client-side) ไม่มีผล ML** — โมเดลรันอยู่ฝั่ง Python บน GitHub Actions เท่านั้น เพราะ scikit-learn
  รันในเบราว์เซอร์ไม่ได้ ดังนั้นตัวเลข ML จะเห็นเฉพาะตอนอยู่ **"โหมดปกติ"** (อ่านจาก `signals.json`)

### วิธีเปิดใช้งาน ML (ต้องทำเพิ่ม 1 ครั้ง)

1. อัปโหลดไฟล์ใหม่ทั้งหมด (`indicators.py`, โฟลเดอร์ `ml/`, `.github/workflows/train-model.yml`,
   `forex_signals.py` และ `requirements.txt` ที่อัปเดตแล้ว) เข้า repo ที่ root เหมือนไฟล์อื่นๆ
2. ไปแท็บ **Actions** → เลือก workflow **"Train ML model"** → กด **Run workflow** ด้วยมือครั้งแรก
   (ใช้เวลานานกว่าปกติเพราะต้องดึงข้อมูลย้อนหลังจำนวนมาก อาจถึง 5-10 นาที)
3. เช็คผลลัพธ์ในหน้า log ของ Actions — จะเห็นตัวเลข accuracy/baseline/ROC-AUC ที่พิมพ์ไว้ตรงๆ
4. ถ้าสำเร็จ จะมีไฟล์ `ml/model.pkl`, `ml/model_meta.json`, และ `ml/data/*.csv` ถูก commit กลับเข้า repo
5. รอบถัดไปที่ workflow **"Update forex signals"** รัน (ทุก 30 นาที) จะเริ่มแสดงผล ML ในแดชบอร์ดเอง
   ไม่ต้องแก้อะไรเพิ่ม

## ⚠️ อ่านก่อนใช้งานจริง

- นี่คือเครื่องมือวิเคราะห์เชิงเทคนิค ไม่ใช่เครื่องทำนายราคา ไม่มีระบบไหนบอกอนาคตตลาดได้แม่นยำ
- สัญญาณคำนวณจากกฎที่ตั้งไว้ล่วงหน้า ยังไม่ผ่านการ backtest — ควรทดสอบย้อนหลังและ paper trade
  ก่อนใช้เงินจริงเสมอ
- โมเดล ML ก็เช่นกัน — เทรนจากข้อมูลจำกัด ไม่รับประกันว่าจะทำงานดีในสภาพตลาดที่ไม่เคยเจอมาก่อน
- ข้อมูลจาก API ฟรีเป็นแบบ delayed/rate-limited ไม่ใช่ tick-by-tick แบบโบรกเกอร์
- เพราะเป็น public repo, ไฟล์ `signals.json`/`ml/data/*.csv` (ราคา+สัญญาณ) จะเป็นข้อมูลสาธารณะ —
  อย่าใส่ข้อมูลบัญชีเทรดหรือข้อมูลส่วนตัวใดๆ ลงในโค้ด ให้เก็บ API key ไว้ใน GitHub Secrets เท่านั้น
  (ดูขั้นตอนด้านล่าง ไม่มีคีย์ไหนหลุดไปอยู่ในโค้ดที่ push)
- ผมไม่ใช่ที่ปรึกษาการเงินที่มีใบอนุญาต เนื้อหานี้เพื่อการศึกษาเท่านั้น การตัดสินใจเทรดและ
  ความเสี่ยงทั้งหมดเป็นของคุณ

## ขั้นตอนติดตั้ง (ทำครั้งเดียว ใช้เวลา ~10 นาที)

### 1. สร้าง GitHub repo

1. สมัคร/ล็อกอิน https://github.com
2. กด **New repository** → ตั้งชื่อ เช่น `forex-signals` → เลือก **Public** → Create

### 2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้เข้า repo

ใช้ได้ทั้งเว็บ (ลาก-วางไฟล์ผ่านปุ่ม "Add file → Upload files") หรือ git บนเครื่อง:

```bash
git init
git add .
git commit -m "init forex signal system"
git branch -M main
git remote add origin https://github.com/<your-username>/forex-signals.git
git push -u origin main
```

> อัปโหลดครั้งเดียวเท่านั้น หลังจากนี้ GitHub จะรันให้เองอัตโนมัติ ไม่ต้อง push อีก

### 3. ขอ API key ฟรีสำหรับข้อมูลราคา (Twelve Data)

1. ไปที่ https://twelvedata.com/pricing กด Free plan แล้วสมัคร
2. คัดลอก API key ที่ได้

### 4. (ไม่บังคับ) ตั้งค่าแจ้งเตือน Telegram

1. คุยกับ [@BotFather](https://t.me/BotFather) ใน Telegram → `/newbot` → ได้ bot token
2. เปิดแชทกับบอทตัวเอง กด Start
3. เปิด `https://api.telegram.org/bot<TOKEN>/getUpdates` ในเบราว์เซอร์ จะเห็น `"chat":{"id": ...}`

### 5. ใส่ค่าเป็น GitHub Secrets (สำคัญ — อย่าใส่คีย์ในโค้ดโดยตรง)

ใน repo ของคุณ: **Settings → Secrets and variables → Actions → New repository secret**
เพิ่มทีละตัว:

| Name | Value |
|---|---|
| `TWELVE_DATA_API_KEY` | API key จากขั้นตอน 3 |
| `TELEGRAM_BOT_TOKEN` | (ถ้าทำขั้นตอน 4) bot token |
| `TELEGRAM_CHAT_ID` | (ถ้าทำขั้นตอน 4) chat id |

### 6. เปิดใช้งาน Actions

ไปแท็บ **Actions** ของ repo → ถ้าขึ้นข้อความให้ enable ก็กด enable →
เลือก workflow **"Update forex signals"** → กด **Run workflow** เพื่อรันรอบแรกด้วยมือ
(ทดสอบว่าทำงานถูกต้อง) หลังจากนั้นมันจะรันเองทุก 30 นาทีตาม cron ที่ตั้งไว้

ถ้ารันสำเร็จ จะเห็นไฟล์ `signals.json` ถูกอัปเดต (commit ใหม่) ใน repo โดยอัตโนมัติ

### 7. เปิดใช้งาน GitHub Pages เพื่อดูแดชบอร์ดออนไลน์

**Settings → Pages** → Source เลือก **Deploy from a branch** → Branch เลือก `main` / `root` → Save

รอ 1-2 นาที แล้วเข้า `https://<your-username>.github.io/forex-signals/dashboard.html`
จากอุปกรณ์ไหนก็ได้ — เว็บจะโหลด `signals.json` ที่อัปเดตจาก Actions มาแสดงผลสด พร้อมกราฟแท่งเทียน

### 8. ติดตั้งลงหน้าจอมือถือ (PWA)

เปิด URL ข้างบนในเบราว์เซอร์บนมือถือ แล้ว:

- **Android (Chrome)** — แตะเมนู `⋮` มุมขวาบน → **"เพิ่มลงหน้าจอโฮม" / "Install app"**
- **iPhone (Safari)** — แตะไอคอนแชร์ (สี่เหลี่ยมมีลูกศรชี้ขึ้น) ด้านล่าง → เลื่อนหาแล้วแตะ
  **"เพิ่มไปยังหน้าจอโฮม" / "Add to Home Screen"**

จะได้ไอคอนแอปบนหน้าจอโฮมเหมือนแอปทั่วไป เปิดแล้วเต็มจอไม่มีแถบเบราว์เซอร์

### 9. (ไม่บังคับ) เปิด "โหมดสด" สำหรับข้อมูลถี่กว่า cron

ในแดชบอร์ด แตะปุ่มจุดวงกลมด้านบน ("โหมดปกติ...") จะมีกล่องให้ใส่ API key ของ Twelve Data
(คีย์เดียวกับที่ใส่ใน GitHub Secrets) โหมดนี้จะดึงราคาตรงจากเบราว์เซอร์คุณเองทุก ~2 นาที
โดยไม่ต้องรอ Actions

⚠️ ข้อควรระวัง: คีย์จะถูกเก็บใน localStorage ของเบราว์เซอร์เครื่องนั้น และปรากฏใน network
request ที่ใครก็ตามเปิด devtools ของเครื่องนั้นมองเห็นได้ — อย่าเปิดโหมดนี้บนเครื่องสาธารณะ
หรือคอมพิวเตอร์ที่ใช้ร่วมกับคนอื่น ถ้ากังวลเรื่องนี้ ใช้แค่โหมดปกติ (อัปเดตทุก 30 นาทีผ่าน Actions)
ก็เพียงพอสำหรับการเทรดที่ไม่ใช่ scalping รายนาที

## ปรับความถี่ / คู่เงินที่ติดตาม

แก้ที่ต้นไฟล์ `forex_signals.py`:

| ตัวแปร | ความหมาย |
|---|---|
| `PAIRS` | รายชื่อคู่เงิน ตอนนี้มี 14 คู่ เช่น `["EUR/USD", "GBP/USD", ...]` |
| `INTERVAL` | timeframe แท่งเทียน เช่น `15min`, `1h`, `4h` |
| `OUTPUT_SIZE` | จำนวนแท่งเทียนย้อนหลังที่ใช้คำนวณอินดิเคเตอร์ |
| `CHART_CANDLES` | จำนวนแท่งเทียนที่บันทึกลง `signals.json` ไว้วาดกราฟ (ค่าเริ่มต้น 80) |

ถ้าแก้ `PAIRS` ให้แก้ `LIVE_PAIRS` ในต้นไฟล์ `dashboard.html` ให้ตรงกันด้วย (ใช้ตอนเปิด "โหมดสด")

**ความถี่การรันจริงควบคุมด้วย cron ใน `.github/workflows/forex-signals.yml`** — ปัจจุบันตั้งไว้ที่
`*/30 * * * *` (ทุก 30 นาที) คำนวณมาจากโควตาฟรีของ Twelve Data (8 requests/นาที, 800/วัน):

| จำนวนคู่เงิน | ความถี่ | requests/วัน | อยู่ในโควตาฟรีไหม |
|---|---|---|---|
| 14 คู่ (ค่าเริ่มต้น) | ทุก 15 นาที | 1,344 | ❌ เกิน |
| 14 คู่ (ค่าเริ่มต้น) | ทุก 30 นาที | 672 | ✅ |
| 8 คู่ | ทุก 15 นาที | 768 | ✅ |
| 14 คู่ | ทุก 5 นาที | 4,032 | ❌ เกินมาก (ต้องใช้แผนเสียเงิน) |

ปรับสมการเองได้: `จำนวนคู่เงิน × (1440 / นาทีต่อรอบ) ≤ 800`

ตรรกะการให้สัญญาณอยู่ในฟังก์ชัน `generate_signal()` ใน `forex_signals.py` — ปรับน้ำหนัก
คะแนนหรือเพิ่ม/ลดเงื่อนไขได้ตามสไตล์การเทรดของคุณ แล้ว commit/push การแก้ไขเข้า repo
Actions จะใช้เวอร์ชันล่าสุดในรอบถัดไปอัตโนมัติ

## อยากรันบนเครื่องตัวเองแทนก็ได้ (ทางเลือกเสริม)

ถ้าเปลี่ยนใจอยากรันเองแบบ real-time ถี่กว่า 15 นาที บนเครื่องที่เปิดทิ้งไว้:

```bash
pip install -r requirements.txt
export TWELVE_DATA_API_KEY=xxxx
```
